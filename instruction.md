# Project Instructions

## Repository

- Main repository: https://github.com/intisarrahmankhan/e-Sikho
- Working branch: `Shirin`

## Change workflow

Whenever a change is requested:

1. Pull or fetch the latest code from `main` and merge it into `Shirin` when needed.
2. Implement and verify the requested change.
3. Run the relevant checks, especially `npm run build` for application changes.
4. Commit the change to `Shirin` with a clear, valid message describing the change.
5. Push the commit to `origin/Shirin`.

Keep unrelated existing work untouched. Report the commit message, verification result, and push status after each completed change.
